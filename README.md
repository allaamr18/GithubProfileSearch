# GitHub Profile Search

A simple web app that lets you search for GitHub users and view their profile information and recent repositories.

## Features

- Search for GitHub users by username
- Display profile picture
- Display name and username
- Display bio
- Display follower and following counts
- Display the 5 most recent public repositories
- Repository names link directly to GitHub
- Handles invalid and empty usernames
- Supports searching by pressing Enter
- Responsive layout

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub API

## How It Works

The application uses the GitHub API to fetch user profile information and repository data.

When a username is entered, the app:
1. Sends a request to GitHub's API.
2. Retrieves the user's profile information.
3. Retrieves their repositories.
4. Displays the profile and 5 most recent repositories.
